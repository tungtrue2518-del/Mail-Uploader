ลายเซ็นดิจิทัล

แนบท้ายอีเมลที่ส่งจากแอปนี้อัตโนมัติทั้ง Thunderbird และ Outlook — ตั้งเป็นข้อมูลของคุณเอง (ใครใช้เครื่องไหนก็ตั้งของตัวเองได้ ไม่ผูกกับคนใดคนหนึ่ง)

ตัวอย่าง:

คิวส่งอัตโนมัติ (Outlook)

โหมดกลางคืน (Dark mode)
ปรับธีมแอปให้เข้ากับการใช้งานตอนกลางคืน
เริ่มแอปอัตโนมัติเมื่อเปิดเครื่อง
เพิ่ม/ลบ shortcut ในโฟลเดอร์ Startup ของ Windows
ระบบทำงานเบื้องหลัง
ปิดหน้าต่างแล้วแอปยังทำงานอยู่ใน system tray (มุมขวาล่าง) + ตั้ง Windows Scheduled Task ตรวจคิวส่งอัตโนมัติทุก 15 นาที แม้ปิดแอปไปแล้วก็ยังปลุก Outlook ให้ส่งได้ตรงเวลา
Reply จริงสำหรับขั้นตอนที่ 2 (Advice)
ให้ขั้นตอนที่ 2 เปิดเป็น Reply บนอีเมล QC เดิมจริงๆ แทนฉบับร่างใหม่ — ต้องติดตั้งส่วนขยาย Thunderbird เองอีกขั้นตอน (ดูวิธีใน SKILL.md) สลับสวิตช์นี้แค่ลงทะเบียนฝั่งแอป ยังไม่ครบขั้นตอนติดตั้งทั้งหมด
